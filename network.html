Baptist Missions Network

Decentralized, censorship-resistant, serverless web publishing for churches and missionaries worldwide using cutting-edge peer-to-peer technology powered by Hypercore and IPFS.

What is the Baptist Missions Network?

The Baptist Missions Network is a revolutionary approach to web publishing that eliminates the need for traditional web servers, hosting fees, and domain registrations. Built on the InterPlanetary File System (IPFS) and Hypercore technology, accessible through the Peersky browser, our network enables churches and missionaries to publish websites and applications that are:

  • Completely Free — No server costs, no hosting fees, no domain renewals
  • Censorship-Resistant — Content cannot be easily blocked or taken down by governments or third parties
  • Offline-Capable — Content can be accessed even without internet connectivity once cached
  • Globally Distributed — Content is replicated across a worldwide network of peers
  • Permanently Available — Content persists as long as it's being accessed
  • Real-time Sync — Hypercore enables instant data synchronization between peers
  • Append-Only Logs — Immutable, verifiable history of all network activity

Peersky Browser

What is Peersky?

Peersky is a groundbreaking web browser designed specifically for the decentralized web. Unlike traditional browsers that only access HTTP/HTTPS content, Peersky natively supports IPFS and other peer-to-peer protocols, allowing you to browse the distributed web without any plugins or extensions.

Key Features

  • Native IPFS and Hypercore protocol support
  • Built-in content caching for offline access
  • Decentralized DNS resolution
  • Real-time peer-to-peer data synchronization
  • No central servers required
  • Privacy-focused architecture
  • Cross-platform compatibility

NovaOS

What is NovaOS?

NovaOS is a fully offline, GPLv3 web desktop that runs entirely in your browser. NovaOS exists for user privacy, self-hostable and with no cloud dependency. Your data stays on your device, what NovaOS apps can know is what you give them.

You can initialize and boot into your NovaOS web desktop within 5 seconds on an average modern device (if self-hosted). Nova Ecosystem is a collection of features, including apps, themes, permission systems, and styling standards.

Key Features

  • NovaOS is mobile friendly, fully local web desktop packaged as a progressive web application.
  • It has a codebase built entirely on pure HTML, vanilla JavaScript, and CSS making it very reliable and private, as it can function fully offline, thanks to its local-first nature.
  • NovaOS lets you encrypt all your imported files by a password, locally without storing the password anywhere.
  • A suite of default applications to ease your work. There's also a store where you can install even more applications!
  • NovaOS is designed for stability and control while having customizability and a wide support. Maintaining simplicity and efficiency in UI. No flashy effects or extensive animations.

IPFS Technology

Understanding IPFS

The InterPlanetary File System (IPFS) is a protocol and peer-to-peer network for storing and sharing data in a distributed file system. Unlike traditional HTTP which locates content by address (where), IPFS locates content by what it is (content-addressed).

How P2P Works for You

When you access content on IPFS, you connect directly to peers who have that content rather than a central server. Each time you view a website, you also help distribute it to others, creating a resilient, self-sustaining network.

Why IPFS Matters for Missionaries

In regions with unreliable internet, strict censorship, or limited financial resources, IPFS provides a way to publish and share content that remains accessible regardless of local infrastructure. Your website lives on the network itself, not on a single server that can fail or be blocked.

Hyper Technology

What is Hypercore?

Hypercore is a distributed, secure append-only log technology that powers real-time data synchronization across the Baptist Missions Network. Built on the Hypercore Protocol, it enables fast, resilient, and peer-to-peer data streams without relying on central servers.

Hyper Features

  • Append-only logs with cryptographic integrity
  • Real-time bidirectional data replication
  • Efficient differential synchronization
  • Built-in end-to-end encryption
  • Works over any transport (WiFi, mesh, sneakernet)
  • Perfect for offline-first applications
  • Cryptographic verification ensures data authenticity

Why Hyper Matters for Missionaries

Hyper technology enables missionaries to share resources, collaborate on documents, and sync data in real-time even across intermittent or low-bandwidth connections. Once content is shared via a Hypercore, it can propagate through any peer connection—even offline mesh networks—ensuring your critical ministry data reaches its destination regardless of infrastructure limitations.
